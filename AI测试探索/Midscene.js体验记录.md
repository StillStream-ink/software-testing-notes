# Midscene.js 体验记录

> 用自然语言驱动 UI 自动化的尝试，基于 v1.10.12 版本


## 背景

日常使用 Playwright 做 Web 自动化测试，需要写精确的定位代码。了解 Midscene.js 后，尝试用自然语言描述操作，AI 自动执行。


## 配置步骤

1. 申请阿里云百炼 Qwen API Key（新用户 100 万 Token 免费额度）
2. 安装 Midscene Chrome 插件
3. 配置模型参数


## 执行测试

在 SauceDemo 商品列表页依次测试了三条指令：

| 指令 | 结果 |
|------|------|
| 提取所有商品名称和价格，以表格形式显示 | ✅ 成功 |
| 点击价格最低的商品，加入购物车 | ✅ 成功 |
| 点击购物车图标，查看购物车内容 | ✅ 成功 |


## 对比：Playwright vs Midscene

| 对比项 | Playwright | Midscene |
|--------|-----------|----------|
| 编写方式 | CSS/XPath 定位器 | 自然语言描述 |
| 执行速度 | 毫秒级 | 秒级（需模型推理） |
| 维护成本 | 定位器失效需手动修复 | AI 自适应识别 |
| 适用场景 | 回归测试、CI | 原型验证、探索性测试 |


## 局限性

1. 执行速度慢于传统定位
2. 按 Token 计费，高频使用有成本
3. 复杂交互（iframe、文件上传等）支持有限
4. 失败排查不如传统方式直观
