## 🧠 测试认知迭代

| 阶段 | 关键认知 |
| :--- | :--- |
| **第一周** | 发现异常 → 直接报Bug |
| **第二周** | 发现异常 → 先确认是系统设计还是缺陷 |
| **第三周** | 测试用例不是给自己看的，是给别人也能复现的 |
| **第四周** | 预期结果必须确定，不能写"或"；测试数据必须精确到可复现 |
